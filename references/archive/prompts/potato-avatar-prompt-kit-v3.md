# 土豆头像风格提示词 v3

本版根据合集中的电脑、床上玩手机、盖被子犯困、抱游戏机四张图重新校准。生成模型使用当前服务支持的 `gpt-image-2.5`。

## 关键风格

整体是低分辨率贴图与简单三维体积结合的旧式 3D 表情包。土豆、衣物和道具必须像同一场景、同一分辨率渲染出来，不能只有角色粗糙而电脑精致。

- 角色：单颗不规则豆形土豆，略收腰；金棕色斑驳贴图；黑点眼、粗短眉毛、黑线嘴；淡黄色胶囊形手脚。面部变化用简单点线和姿态表达。
- 材质：偏灰的低清贴图，细节稍糊，阴影简单、柔和；轮廓轻微锯齿。保持三维体积，避免一味增加尖锐多边形或做成像素画。
- 布料：参考图中的灰绿与米白格纹、宽米白翻边；图案是模糊贴图，随少量圆缓褶皱弯曲。不要毛绒、纤维细节或折纸状三角面。
- 电子设备：略笨重的简单模型，暗灰或灰褐贴图，粗略键盘，软化的不规则边缘；标志小而低清，不出现精致金属反射和清晰矢量边缘。
- 构图：一个角色，纯白或单色背景，主体约占 75%，四周留白；道具低于面部，不遮住表情。
