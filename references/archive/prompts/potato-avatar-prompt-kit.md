# 土豆头像提示词套件

这套提示词使用视觉特征描述，不使用原作者或角色名称。生成时固定“角色骨架”，只替换动作、情绪、服装、道具和场景。

## 风格母提示词

一个可爱又略显笨拙的拟人化土豆角色，身体是一颗短胖、略不规则的真实马铃薯，保留自然的浅棕色表皮、细小斑点、凹凸纹理和轻微干燥质感；面部由简洁的黑色圆眼、粗短眉毛和小嘴组成，表情清晰夸张但不过度卡通；四肢短小，颜色接近削皮后的淡黄色土豆，动作具有玩偶般的僵硬感。整体采用写实材质与简洁卡通造型结合的 3D 角色摄影风格，像手工制作的土豆玩偶或定格动画模型，造型朴拙、幽默、治愈。柔和均匀的棚拍光线，轻微接触阴影，材质清楚但不过分油亮。主体完整、居中、占画面约 70%，正方形头像构图，背景简洁，边缘清晰，高分辨率。

## 可直接使用的模板

```text
一个可爱又略显笨拙的拟人化土豆角色，短胖而略不规则的真实马铃薯身体，浅棕色天然表皮，带细小斑点、凹凸纹理和轻微干燥质感；简洁的黑色圆眼、粗短眉毛和小嘴，短小的淡黄色手脚。角色正在【动作】，表现出【情绪和表情】，穿着【服装】，拿着或使用【道具】。写实土豆材质与简洁卡通造型结合的 3D 玩偶摄影风格，带一点定格动画和手工模型质感，朴拙、幽默、治愈。柔和均匀的棚拍光线，轻微接触阴影，材质清楚但不过分油亮。主体完整、居中、占画面约 70%，【背景要求】，正方形头像构图，边缘清晰，高分辨率。
```

## 固定约束

```text
保持同一个角色设计：单颗土豆作为身体，不增加脖子，不使用人类皮肤，不做成人类比例，不改变为光滑塑料或毛绒玩具；眼睛保持简单黑色圆点，眉毛粗短，四肢短小；保留真实土豆表皮纹理。画面只出现一个主要角色，除非需求明确要求多个角色。不要复杂背景，不要裁掉头顶、手脚或主要道具，不要文字、签名、标志和水印。
```

## 以后输入新效果的格式

只需要告诉我变化部分，例如：

```text
动作：抱着一台小 MacBook 工作
表情：困得睁不开眼，但还在强撑
服装：深灰色连帽衫
道具：电脑和一杯咖啡
背景：纯白
希望生成：4 个方案
```

我会把这些变量填入母提示词，先生成第一轮，再根据结果调整角色一致性、构图、表情力度、材质和道具位置。

## 常用优化指令

- 更接近头像：`主体再放大 15%，减少留白，保持四肢完整。`
- 更像真实土豆：`增加天然表皮斑点和细微凹凸，降低塑料光泽。`
- 更可爱：`身体更短胖，手脚更短，眼睛略微靠近，表情更含蓄。`
- 更搞笑：`加强眉毛和嘴部表情，动作更笨拙，但不要扭曲肢体。`
- 保持角色一致：`严格沿用参考图的身体比例、表皮材质、眼睛、眉毛和四肢设计，只改变动作与道具。`
- 改白底头像：`使用纯白无缝背景，只保留轻微接触阴影。`
- 改彩色背景：`使用单一低饱和背景色，不加入复杂场景，确保轮廓清楚。`
