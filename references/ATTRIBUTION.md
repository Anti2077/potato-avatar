# Reference attribution

The PNG examples were generated for the potato-avatar workflow in September 2026. The first three MacBook/blanket rounds used `gpt-image-2`; rounds four and five and the subsequent scene examples used `gpt-image-2.5`. Resolution experiments include non-generative post-processing. These are historical provenance records, not required models. They are included as calibration examples for this open-source skill.

No original creator images, downloaded sticker sheets or watermarked third-party assets are included in this repository. The local project may contain additional user-authorized source references; those remain outside this public package.

The skill text and examples are provided under the repository license. Image-model terms and the user's configured provider terms may apply separately to generated outputs.

The extended archive includes original prompt text for study. Some numbered reference inputs mentioned there were third-party images and are not included; the archive is not a claim of fully reproducible input sets. Review contact sheets are assembled solely from the included generated examples.
