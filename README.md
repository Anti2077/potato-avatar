# potato-avatar

一个用于 Codex 的土豆头像 skill：帮助生成方形、低清、粗糙三维表情包风格的土豆头像，并保持动作、道具和材质质感一致。

## 风格重点

这套风格追求的是**弱物理真实感**，不是简单加像素。土豆可以有适度的圆润体积，但道具更简单、更薄、更少材质细节；所有物件使用相近的低清贴图、弱明暗和轻微锯齿边缘。

它适合“土豆在做某件事”的新头像，例如打羽毛球、打碟、喝冰水、弯举哑铃或被切成薯条。

## 安装

把整个仓库目录复制到个人 skills 目录：

```sh
cp -R potato-avatar "$HOME/.codex/skills/potato-avatar"
```

也可以把仓库目录作为本地 skill 路径使用。本 skill **不绑定生图工具或模型**：先遵循用户指定的工具，否则从当前环境中选择可用的生图能力，例如内置 `imagegen` / `image_gen`、`codex-image2` 或其他已安装的生图 skill。

优先选择已经可用且支持参考图的工具，按该工具自身的说明执行。未指定模型时使用该工具支持的默认模型；是否需要凭据取决于所选工具，本仓库不保存 API key。仅支持文字的工具也可使用，但需说明角色一致性的控制更弱。

参考图来源里记录的 `gpt-image-2.5` 只是历史生成信息，不是使用条件。

## 使用

```text
使用 $potato-avatar，生成一只土豆坐在月亮上吃泡面，表情很满足。
```

如果新场景需要道具，说明动作和空间关系，例如“左手按住唱片、右手调混音器，脸不能被遮住”。skill 会从 `references/images/` 选择相关示例，不会把旧场景的耳机、被子或表情自动带入新图。

## 参考图

仓库包含 **23 张去重的生成示例与实验版本、17 份历史提示词，以及各轮反馈记录**。默认从 8 张基础参考中挑选；不够时查[扩展参考库](references/extended-library.md)，先批量看图，再按动作、道具和材质补充。已认可方向、待确认候选、未采用实验分别标注，旧文件名中的 approved 不代表逐张获认可。原作者的第三方表情包和水印素材没有放进公开仓库；本地使用时可以自行提供有授权的参考图。
